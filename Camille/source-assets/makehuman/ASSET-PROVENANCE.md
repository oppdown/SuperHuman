# MakeHuman starter mesh provenance

The starter file in this folder is a byte-for-byte copy of `Human_Female_BaseMesh.blend` supplied in the local MakeHuman Blender 5.2.1 project folder and shown open in the user's screenshot. The local copy's SHA-256 was checked against the original. The exact upstream download package and MakeHuman release that produced this specific `.blend` file are unknown.

MakeHuman Community's documentation identifies the core base mesh and core graphical assets as CC0:

- [MakeHuman asset license](https://static.makehumancommunity.org/about/license.html)
- [MakeHuman FAQ: reusing system assets](https://static.makehumancommunity.org/mpfb/faq/build_other_chargen.html)

This note describes the license status of MakeHuman's core base mesh, not every possible item that could be embedded in a Blender project. It does not license Camille's generated references or the separately developed Camille head/ear assets. No overall license is granted for this repository. The original local file remains preserved; this repository copy is a source snapshot and has not been edited.
