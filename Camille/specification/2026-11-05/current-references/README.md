# Camille - athletic Blender character sheet

This package contains the latest athletic visual pass and a multipage Blender modeling/rigging guide. Camille is a fictional adult character. User-assigned barefoot height is 165.1 cm (5 ft 5 in), floor to anatomical skull vertex. Rigify was enabled in the local Blender 5.2.1 preferences. MPFB was already installed and left unchanged; its generic base is not Camille.

## Reference status
- Front, left profile and rear: latest generated appearance references. They are not calibrated orthographic renders of one mesh.
- Top and bottom: best available generated angles, included at the user's direction. They are approximate appearance references; exact 0-degree orthographic camera alignment is not verified.
- All non-height measurements are estimates, provisional targets, or unknowns as labeled. Decimal formatting is for Blender entry convenience only.

## Files
- `camille-athletic-character-sheet-2026-11-05.pdf`: 12-page modeling, proportions, anatomy, rig and measurement worksheet.
- `camille-blender-measurements-2026-11-05.json`: coordinate and rig starter data.
- `current-references/`: source PNG references and original handoff context.

Build a single mesh, measure it directly, then regenerate all views with saved orthographic cameras before treating any dimension as final.
