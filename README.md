# SuperHuman

Public source and research repository for the SuperHuman character projects. Each character gets a separate top-level folder so future models can share the same project without mixing their references or review histories.

## Projects

- [Camille](Camille/README.md) - athletic adult character, Blender source mesh, measured design handoff, and linked head/ear research.

Character models and project references are kept under their character folder. A project index records source paths, evidence confidence, candidate status, and review history. No blanket reuse license is granted by this repository; check the provenance note beside each third-party asset.
